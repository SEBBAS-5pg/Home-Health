# Story Map — Home-Health

## Descripción

El siguiente Story Map representa el flujo funcional principal de la plataforma **Home-Health**, incluyendo:

- actividades principales del usuario,
- tareas por módulo,
- separación por roles,
- historias de usuario asociadas,
- priorización funcional del MVP.

Este artefacto fue utilizado para organizar el alcance funcional del sistema antes del diseño del modelo de datos y la arquitectura backend.
