# Mockups y Prototipo UI/UX — Home-Health

## Descripción

El siguiente enlace contiene el prototipo visual y los mockups desarrollados para la plataforma **Home-Health** en Figma.

El diseño incluye las principales vistas del sistema para clientes y administradores, contemplando funcionalidades relacionadas con autenticación, gestión de productos, inventario, pedidos, reportes y notificaciones.
