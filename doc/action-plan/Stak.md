# 3 Stack Tecnológico y Orquestación de IA

Definimos las herramientas y cómo los agentes de IA nos ayudarán en cada una.

| Capa                | Framework / Lenguaje          | Uso de IA (Agentes)                                    | Cuándo usarlo                          |
| :------------------ | :---------------------------- | :----------------------------------------------------- | :------------------------------------- |
| **Frontend**        | **Next.js + Tailwind**        | Generación de componentes UI y hooks de datos.         | Fase de maquetación y consumo de API.  |
| **Backend**         | **NestJS (Node.js)**          | Boilerplate de módulos, servicios y controladores.     | Fase de lógica de negocio y seguridad. |
| **Persistencia**    | **Prisma (Postgres + Mongo)** | Generación de modelos y migraciones.                   | Fase de modelado de datos.             |
| **Infraestructura** | **Terraform / AWS CDK**       | Creación de recursos en AWS Fargate y VPC.             | Fase de despliegue y DevOps.           |
| **Documentación**   | **Markdown**                  | Redacción de READMEs y registros de decisiones (ADRs). | Durante todo el ciclo de vida.         |
