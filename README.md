# 💡 ¿Por qué y para qué este plan?

1.  **¿Por qué este diseño?**: Al ser un estudiante de 6to semestre, el docente evaluará tu capacidad de **abstracción**. Usar **C4** demuestra que no solo programas, sino que diseñas. Usar **AWS Fargate** (según tus documentos) te posiciona como un perfil que entiende el costo operativo y la eficiencia en la nube.
2.  **¿Para qué la persistencia políglota (Postgres + Mongo)?**: Para demostrar que sabes elegir la herramienta adecuada. Postgres cuida el dinero (transacciones), Mongo cuida la agilidad (catálogo flexible de productos médicos).
3.  **¿Para qué los Agentes (`agent.md`)?**: Para que no pierdas tiempo en sintaxis. La IA se encarga de que el código sea **Clean Code** (siguiendo a Robert C. Martin), mientras tú te encargas de la **Arquitectura**.
4.  **¿Para qué la Chain of Responsibility?**: En una farmacia, el stock es crítico. Si no tienes "Aspirina Marca A", el sistema debe ofrecer automáticamente la "Marca B". Este patrón permite encadenar estas reglas de negocio de forma limpia y desacoplada.
